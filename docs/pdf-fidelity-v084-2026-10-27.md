# 0.8.4 PDF 대조 및 렌더링 개선

2026-10-27. 윤리기준 17쪽, 규제합리화 20쪽, 식약처 4쪽, 총 41쪽을 원본 PDF와 나란히 검토했다. 쪽수는 파일의 실제 페이지 순서다. 전체 연락 시트와 확대 비교는 `build/pdf-audit-v084/`에 있다. PDF를 수정하거나 PDF 이미지를 앱 화면 대신 표시하지 않고, HWPX 엔진을 개선했다.

## 수정 사항

| 차이 | 원인과 개선 | 확인 |
|---|---|---|
| 윤리기준 5쪽 도해가 검은 배경 | WIC BGR 변환이 알파를 버렸음. PBGRA 디코딩과 배경 합성, 투명 그림의 Fant 리샘플링 적용 | 실제 5쪽 및 투명·반투명·불투명 픽셀 검사 |
| 윤리기준 2쪽 목차 점선 누락·쪽번호 정렬 | 탭을 공백으로 바꾸던 처리를 제거. 탭 너비·리더·오른쪽 정렬을 유지 | 실제 목차, 점선 픽셀 검사 |
| 여러 쪽 상자 번호가 빈 네모 | HWP 사설 영역 U+F02B1~F02B4에 대해 상자와 숫자를 직접 그림 | 원문 보존, 번호 내부의 실제 잉크 검사 |
| 윤리기준 6쪽 국민·행정 셀의 오른쪽 쏠림 | 저장된 가로 위치에 문단 왼쪽 여백을 중복 더했음 | 중복 제거 및 실제 6쪽 확대 확인 |
| 윤리기준 13쪽 안내문이 14쪽으로 이동 | 부동 표를 인라인 객체처럼 원문 순서대로 배치했음 | 양의 문단 상대 오프셋을 가진 표의 앵커 텍스트를 먼저 배치. 안내문이 13쪽에 한 번 나타나는지 검사 |
| 표 선이 굵거나 서로 다름 | 한 면의 선 두께가 모든 면에 적용되고 인접 셀 선이 별도 픽셀에 그려짐 | 면별 두께, 공유 경계, DOUBLE_SLIM 이중선 적용 |
| 페이지 끝 표 가로선 잘림 | 행 경계와 정확히 일치하는 분할에서는 마지막 선이 클립 영역 밖에 놓임 | 실제 식약처 3쪽 및 행 경계 픽셀 검사. 원래 선이 없는 표에는 선을 추가하지 않음 |
| 병합 셀·열 너비의 오차 | 단일 셀이 없는 열은 균등 폭 추정, 열별 반올림 오차 누적 | 병합 셀의 합계 너비 제약과 누적 경계 반올림 적용 |
| 글자의 색 테두리 | LCD용 ClearType을 문서 비트맵에 사용 | 회색 안티앨리어싱 적용 |
| 일반 그림의 선명도 | AlphaBlend 확대·축소는 최근접 보간을 사용 | 불투명 그림 HALFTONE 유지, 투명 그림만 WIC 리샘플링 후 합성 |

## 검증

- CTest 23개 통과. 마지막 경계선 조건 변경 후 관련 GDI 검사도 재실행했다.
- 원본 페이지 수 17/20/4 유지, 강제 글자 분할 0건. 합성 병합 표 2쪽 회귀 검사 포함.
- 자체 시각 기준을 검토 후 17개 PNG로 확장: 윤리기준 1/2/3/5/6/13/14/17, 규제합리화 1/4/18/20, 식약처 1/3/4, 합성 표 1/2.
- 기존 편집·저장·재열기·패키지 보존 검사 통과. 원본 샘플 HWPX/PDF는 수정하지 않음.
- `build/pdf-audit-v084/comparison.json`: 41쪽의 이전/현재 픽셀 차이 수치. 렌더러·안티앨리어싱 영향을 받는 보조 지표이며 정확도나 누락률이 아님.
- `build/pdf-audit-v084/detail-ethics-*.png`: 원본 PDF/개선본 확대 비교.
- `build/pdf-audit-v084/*-sheet.png`: 전체 41쪽 연락 시트.

## 한계

이번 작업은 전체 페이지의 시각 대조와 확인된 엔진 오류 개선이다. 모든 문자의 의미를 OCR로 전수 검증하거나, PDF와 픽셀 완전 일치를 달성했다는 뜻은 아니다. 원본 PDF의 포함 글꼴·폰트 엔진·힌팅과 Windows GDI의 출력 차이, 일부 표 셀 줄바꿈과 이미지 배치 차이는 남아 있다. 상자 번호는 확인한 1~4만 보완했으며 다른 모든 HWP 사설 글리프의 일반 해석기는 아니다. 목차 오른쪽 탭은 현재 문단의 오른쪽 경계를 기준으로 배치하며 임의의 복수 사용자 탭 정지점 전체를 지원하는 것은 아니다.
