# 0.7.0 원본 글꼴·서식과 화면 배치 수정

## 반영한 내용

- 한글·영문·한자·일본어·기타·기호·사용자 문자별 원본 글꼴 테이블 및 글꼴 ID를 보존한다. 문자별 대체에도 해당 원본 글꼴과 크기·굵기·기울임·밑줄·단일 취소선 정보를 유지한다.
- 설치 글꼴의 영문/한글 이름 차이만으로 대체 내역을 만들지 않는다. 구형 문서의 비활성 취소선 자리표시자 `shape=3D`를 실제 취소선으로 해석하지 않는다.
- 글자 폭을 1/8 픽셀 단위로 측정하여 글자마다 정수 픽셀 오차가 누적되는 것을 줄인다. 저장된 기준선에 맞춰 크기와 글꼴이 다른 문자들을 배치한다.
- 셀 자체 여백 지정 여부(`hasMargin`)를 읽고 표 여백 상속을 처리한다. 셀의 위/가운데/아래 정렬을 실제 그리기와 페이지 분할용 글자 영역 계산에 함께 적용한다.
- 테두리가 없는 셀에 회색 안내 테두리를 임의로 그리지 않는다.
- 그림의 `imgClip`을 `imgDim` 좌표계로 적용한다. 넓은 로고 이미지의 일부만 잘라 쓰는 경우 전체 이미지를 좁은 영역에 압축하지 않는다.
- 머리말/꼬리말 예약 공간을 본문 영역 계산에 반영한다. 단일 블록 문단은 앞선 글자와 겹치지 않는 범위에서 원본 세로 좌표를 사용한다.
- 작은 저장 빈 줄을 8픽셀 이상으로 강제하지 않으며, 그림·그룹 뒤에 임의의 8픽셀 간격을 추가하지 않는다. 페이지 끝의 보이지 않는 줄 간격만 넘치는 경우 불필요한 새 쪽을 만들지 않는다.

## 검증

- CTest 16개 통과. 문자별 원본 글꼴, 기울임/밑줄/취소선, 여백 상속, 기준선, 그림 잘라내기 메타데이터 검사 추가.
- 회귀 덤프 변경을 검토하여 기존 출력과의 차이가 의도한 셀 여백 변경뿐임을 확인하고 golden 파일을 갱신했다.
- 현재 샘플 3쌍 41쪽 전체를 최신 GUI와 동일한 GDI 그리기로 렌더링했다. 페이지 수는 규제합리화 20, 식약처 4, 윤리기준 17이다. 강제 글자 분할은 0건이다.
- 이전 엔진과 최신 엔진의 텍스트 run 문자열 순서가 3개 문서 모두 동일하다. 비교 run 수에는 기존 IR 덤프의 블록 목록과 평탄 문단 목록이 포함된다.
- 현재 사용된 글자 스타일의 언어별 상대 크기는 모두 100%, 기준 위치 이동은 모두 0%임을 확인했다.

## 남은 차이

원본이 설치되지 않은 글꼴의 외형 차이, 일부 양쪽 정렬·줄바꿈, 점선 등 선 종류, 여러 쪽 표의 행 분할 위치, 목차 탭 리더 및 구역별 쪽번호는 아직 원본 PDF와 완전히 같지 않다. 텍스트 보존은 화면상의 모든 기호나 이미지 내부 문자를 OCR로 전수 검증했다는 뜻이 아니다.
