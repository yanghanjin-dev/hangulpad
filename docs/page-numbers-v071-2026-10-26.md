# 0.7.1 구역별 쪽번호 수정

## 동작

상단의 페이지 이동 표시는 문서의 실제 페이지 순서다. 종이 위 쪽번호는 별도로 계산한다.

- 구역의 `startNum page`가 양수이면 해당 번호에서 시작한다. 0이면 이전 구역의 번호를 이어간다.
- `newNum numType=PAGE`는 제어가 들어 있는 페이지 전체의 번호를 다시 시작한다. 제어가 그 페이지의 마지막 표에 있어도 다음 페이지부터 적용하지 않는다.
- `pageHiding hidePageNum`은 그 제어가 놓인 한 페이지만 숨긴다. 구역의 `hideFirstPageNum`도 반영한다. 숨긴 페이지도 번호 계산에는 포함한다.
- 쪽번호 위치와 앞뒤 장식 문자를 읽는다. 쪽번호 지정이 없는 최초 구역에는 임의의 번호를 출력하지 않는다.
- 표가 여러 쪽으로 이어질 때 시작 번호와 감추기 제어를 반복하지 않는다.

## 검증

CTest 16개 통과. 시작 번호 지정, 구역 번호 이어매기기, 페이지 중간 재시작, 한 페이지 감추기, 계속 표의 제어 비반복 검사를 포함한다.

샘플 PDF 41쪽의 하단 텍스트에서 인쇄 번호를 추출하여 렌더러의 페이지별 번호·표시 여부와 대조한다.

| 문서 | 실제 페이지 수 | 인쇄 쪽번호 |
|---|---:|---|
| 규제합리화 보도자료 | 20 | 1~20 |
| 프로프라놀롤 안내 | 4 | 1~4 |
| 공공부문 인공지능 윤리기준 | 17 | 표지·목차 숨김, 본문 1~15 |

윤리기준의 실제 9번째 페이지는 인쇄 번호 7이다. 전체 페이지 수는 변경되지 않는다. 기존 글꼴·표·줄바꿈 등 다른 화면 차이를 이번 수정에서 해결했다고 판단하지 않는다. 숫자 외의 로마자·한글 쪽번호 모양은 이번 샘플 검증 범위가 아니다.

개발 검증 산출물: `build/page-numbers/page-number-verification.json`, `build/page-numbers/comparison/`.
