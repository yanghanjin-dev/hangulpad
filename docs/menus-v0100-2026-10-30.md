# 0.10.0 메뉴와 기능

2026-10-30. 사용자가 보낸 한글 2010 화면과 도움말(hwpkor.chm, hwpenu.chm)을 참고했다. 메뉴 이름, 메뉴 순서, 단축키는 도움말의 "메뉴 비교"와 "단축키 일람"을 따랐다. 아이콘과 그림은 한컴 것을 쓰지 않았고 모두 직접 그렸다.

## 화면 구성

```
┌ 메뉴: 파일(F) 편집(E) 보기(U) 입력(D) 모양(J) 도구(K) 표(Q) 창(W) 도움말(H)
├ 기본 도구 상자: 새 문서·불러오기·저장 | 인쇄·미리 보기 | 오려 두기·복사·붙이기·되돌리기 |
│                 찾기·글자 모양·문단 모양·편집 용지·문자표 | 본문 편집 | 이전·다음 쪽 | 쪽 맞춤·폭 맞춤·두 쪽·[배율]
├ 서식 도구 상자: [스타일][글꼴][크기] | 가 가 가 가 가(색) | 양쪽·왼쪽·가운데·오른쪽·배분 | [줄 간격]
├ 쪽 보기 (모든 쪽을 이어서 스크롤)    ← 편집 중: 문단 목록 | 입력창 + 쪽 미리 보기
└ 상황선: 쪽 | 구역 | 문단 | 배율 | 형식 | 안내
```

- 소스: `src/gui_ui.inc`. 이 파일에 메뉴 표, 도구 상자, 상황선, 쪽 보기 창(`HangulPadView`), 대화상자, 찾기, 인쇄, 단축키가 들어 있다. `gui_win.c`에는 문서 배치와 그리기만 남겼다.
- 대화상자는 리소스 파일 없이 메모리에서 만든다(DLGTEMPLATE). 글꼴은 맑은 고딕 9pt이고, 화면 배율은 윈도우가 맞춘다.
- 도구 상자 아이콘은 실행할 때 화면 배율 크기로 그린다. 윈도우 10/11에 있는 기호 글꼴(Segoe Fluent Icons 또는 Segoe MDL2 Assets)을 쓰고, 이 글꼴이 없으면 한 글자 이름으로 대신 표시한다. 서식 단추("가")와 정렬 단추는 항상 직접 그린다.

## 단축키

한글 단축키 일람을 따랐다. 기존 한글패드 단축키와 겹치는 것은 다음 두 가지를 정해서 처리했다.

- **F2**: 한글에서는 찾기다. 한글패드에서는 0.8.0부터 본문 편집으로 써 왔으므로 그대로 두었다. 찾기는 Ctrl+F와 Ctrl+Q,F로 쓸 수 있다.
- **Ctrl+N**: 한글에서는 Ctrl+N,T(표)처럼 두 글쇠 단축키의 앞 글쇠다. 한글패드에는 표 기능이 아직 없으므로 윈도우 관례대로 새 문서로 쓰고, Alt+N도 함께 둔다.

두 글쇠 단축키는 앞 글쇠(Ctrl+Q, Ctrl+G, Ctrl+K, Ctrl+M)를 누르면 상황선에 안내가 나오고, 다음 글쇠로 명령을 고른다.

- Q: I/D 문서 정보, F 찾기, A 찾아 바꾸기, L 거꾸로 찾기
- G: P 쪽 맞춤, W 폭 맞춤, Q 100%
- K: D 날짜/시간 문자열
- M: K 검정, R 빨강, B 파랑, D 자주, G 초록, Y 노랑, C 청록, W 흰색

## 글자·문단 모양 저장 방식 (엔진)

API(`include/hp/edit.h`):

- `hp_editor_get_format(e, i, &cf, &pf)`: 문단의 첫 run이 쓰는 글자 모양과 문단 모양을 읽는다. 문단 모양은 `HwpUnitChar` case 쪽 값을 쓴다. 아직 저장하지 않은 변경이 있으면 그 값을 덮어 돌려준다.
- `hp_editor_apply_char_format` / `hp_editor_apply_para_format`: `fields` 비트로 지정한 항목만 바꾼다.

저장은 다음 순서로 한다.

1. 텍스트 패치를 적용한다(0.8.0 방식 그대로).
2. 서식을 바꾼 문단이 있는 구역만 다시 읽어서, 해당 문단의 `paraPrIDRef`와 각 run의 `charPrIDRef`를 새 번호로 바꾼다.
3. 새 번호는 `(원래 모양 번호, 바꾼 내용)` 조합마다 하나씩 만든다. 원래 `<hh:charPr>`/`<hh:paraPr>` 텍스트를 복제한 뒤 다음 항목을 고친다.
   - id, height, textColor
   - fontRef(7개 언어)
   - bold·italic 요소를 넣거나 지운다.
   - underline type, strikeout shape
   - align horizontal
   - margin: case 쪽 값, default 쪽은 그 2배, switch가 없으면 값 그대로
   - lineSpacing PERCENT
4. 새 항목은 `charProperties`/`paraProperties` 끝에 추가하고 `itemCnt`를 고친다. 문서에 없는 글꼴은 7개 `fontface`에 각각 추가하고 `fontCnt`를 고친다. 글꼴 목록이 없는 언어는 건너뛴다.
5. 서식을 바꾼 문단의 `linesegarray`를 지워서 다시 배치하게 한다.

run마다 원래 모양을 복제하므로, 바꾸지 않은 속성(장평, 자간, 그림자, 테두리 등)과 run마다 다른 값이 그대로 남는다. 바꾸지 않은 부품, 구역, 문단은 바이트까지 같다.

## 남은 일

1. 서식을 바꾼 HWPX가 한컴오피스에서 열리는지 PC에서 확인한다.
2. 문단 안 일부 글자에만 서식을 적용한다. run을 나눠야 하고, 쪽 위에서 직접 편집(WYSIWYG)하는 것과 함께 다룬다.
3. 편집 용지를 바꿀 수 있게 하고(secPr의 pagePr 패치), 스타일 목록을 표시한다.
4. 도구 상자 아이콘이 윈도우 10/11 실제 화면에서 어떻게 보이는지 확인한다. Wine에는 기호 글꼴이 없어서 대체 글자로만 확인했다.
