# 0.8.3 연속 밑줄과 표 점선

## 원인과 수정

제목의 BOTTOM 밑줄을 GDI 글꼴 장식에 맡긴 채 글자를 각각 그리면, 글꼴 공백 폭과 문서의 실제 이동 폭 차이 때문에 선이 끊어진다. 기본 글꼴 밑줄은 끄고, 문서의 자간·공백·정렬 보정을 포함한 이동 구간 전체에 밑줄을 그린다. 밑줄 없는 글자는 그대로 유지한다.

표의 borderFill에서 선 존재 여부와 색만 읽던 리더를 확장하여 네 면의 선 종류를 각각 보존한다. 실선·짧은 점선(DASH)·DOT·일점쇄선·이점쇄선·긴 대시를 구분하고, 굵은 점선도 실선으로 변하지 않도록 장치 좌표의 선분으로 그린다. 연속 표의 경계선에도 해당 면의 선 종류를 적용한다.

윤리기준 3쪽의 설명 표는 표 자체 borderFill 7이 SOLID지만, 실제 셀의 borderFill 22가 네 면 모두 DASH다. 셀의 설정을 유지하여 네 면을 짧은 점선으로 표시한다. 하단 법률 표의 실선은 유지한다.

## 검증

- CTest 22개 통과. 새 gui-decorations는 실제 제목을 비트맵에 그리고 415 px 이상의 연속 검은 선이 공백과 run 경계를 가로질러 존재하는지 검사한다. 밑줄 없는 대조군에 선이 생기지 않는 것도 검사한다.
- 실제 셀의 네 면이 DASH로 읽히는지 확인하고, 가로·세로·굵은 점선의 간격 및 실선의 연속 픽셀을 검사한다.
- 기존 페이지 배치·저장·편집·golden 검사를 유지한다. 샘플 페이지 수 17/20/4쪽 및 강제 글자 분할 0건을 유지한다.
- 비교 산출물: `build/decorations-v083/decoration-comparison.png`.
