# 페이지 나눔·표 잘림 개선 가능성 조사 (0.3.2, 2026-10-26)

## 결론
둘 다 개선 가능하다. 원본 데이터 부재가 아니라 리더/문서 모델/레이아웃에서 정보가
누락되거나 적용되지 않는 문제다. 명시적 나눔 지원과 표 텍스트 폭 보정을 먼저 하고,
자동 페이지 및 긴 표 분할은 별도 단계로 검증하는 것이 적절하다.
제품 소스와 EXE는 이번 조사에서 변경하지 않았다.

## 원본 페이지 나눔
원본 XML의 최상위 문단 pageBreak=1 개수: 윤리기준 8, 규제합리화 14, 식약처 1.
윤리기준은 2개 구역, 나머지는 각각 1개 구역이다.
리더 parse_section_paragraph는 pageBreak/columnBreak를 읽지 않는다.
IR의 hp_block/hp_paragraph에 나눔 정보가 없고, GUI rebuild_pages는 높이 초과 여부만 검사한다.
구역별 블록을 평탄화하고 첫 구역의 설정으로 배치하므로 구역 경계도 그대로 보존하지 않는다.

윤리기준 표지 다음 '목 차' 문단은 pageBreak=0이나 첫 줄 vertpos가 앞 문단의
58795에서 0으로 되돌아간다. 따라서 명시적 pageBreak만 지원해서는 표지/목차 문제가 모두
해결되지 않는다. 저장된 좌표 초기화, 구역 경계, 자동 페이지를 함께 고려해야 한다.
규제합리화에서도 문단 사이 좌표 감소가 19회 보이나, 좌표 감소만으로 페이지를 확정하면
다단·떠있는 개체 등을 오판할 수 있어 컨텍스트별 처리와 검증이 필요하다.
문단 안 좌표 감소는 현 line_layout.h가 연속 흐름으로 이어 붙이므로 페이지 분할 표현이 필요하다.

### 제안
1. 블록에 break_before/column_break와 원본 문단 연관 정보를 보존.
   표·그림만 있는 문단 및 빈 문단도 나눔이 누락되지 않도록 처리.
2. GUI가 명시적 나눔과 구역 경계를 우선 반영. 페이지별 구역·용지·여백 정보 관리.
3. 저장 좌표를 이용한 자동 페이지 경계와 문단/표의 페이지별 조각 배치를 구현.
   자동 경계와 강제 경계 중복으로 빈 페이지가 생기지 않게 테스트.

## 표 내부 잘림
0.3.2 규제합리화 GUI를 다시 실행해 첫 페이지 제목 오른쪽 잘림을 재현했다.
원본 제목 '대통령 주재 규제합리화위원회 제2차 전체회의 개최'의 정보:
- 셀 width=47533 HWPUNIT, 좌우 여백 각 510, 줄 horzsize=46512.
- 글자모양 244: 23pt, 함초롬돋움, 굵게, 장평 ratio=99, 자간 spacing=-14.
- 문단모양 80: 가운데 정렬.
현재 IR/리더는 장평·자간을 저장하지 않으며, GUI map_face는 함초롬돋움을
설치 여부와 무관하게 Malgun Gothic으로 치환한다.
lineseg 경로는 글자를 TextOutW로 하나씩 그리며 GDI 글자 폭만 누적한다.
저장된 horzsize와 가운데 정렬을 반영하지 않고, 셀 단위 클리핑도 없다.
표가 가용 폭으로 축소되면 열 너비는 바뀌지만 원래 줄 좌표/글자 폭과의 동기화가 없다.
측정 함수와 그리기 함수의 열/병합 셀 너비·여백 계산도 분리돼 있다.
이 조합은 셀 밖으로 넘침과 용지 경계에서 잘림을 설명하며, 각 요인의 기여율은 미측정이다.

### 제안
1. 실제 설치 글꼴 우선 사용, 장평/자간을 언어별로 IR에 보존·적용.
2. 줄의 실제 글리프 폭을 계산해 가운데/오른쪽 정렬과 저장된 줄 가용 폭을 반영.
3. 셀·병합 셀 너비, 여백, 표 축소율을 공통 레이아웃 결과로 측정/그리기에 공유.
4. 셀 밖 출력은 클리핑으로 막되, 내용이 잘리지 않도록 줄바꿈/행 높이 계산을 함께 적용.
   클리핑만 추가하거나 임의로 글자를 축소해 원본 재현 완료로 판정하지 않는다.

## 우선순위/완료 기준
- 1단계: 명시적 페이지/단 나눔, 구역 경계 보존 + 해당 IR/레이아웃 회귀 테스트.
- 2단계: 규제합리화 제목의 원본 폰트·장평·자간·셀 폭 반영 + 셀 밖 출력/글자 누락 검사.
- 3단계: 자동 페이지, 긴 문단/표 분할, 다단·구역별 용지 조건 확대.
- 각 단계 CTest/golden을 실행하고 원본 HWPX와 PDF의 페이지 소속·제목 전체 표시를 확인.
페이지 수만 일치한다고 통과시키지 않으며 전 샘플의 모든 페이지는 별도 검증이 필요하다.
