# 0.4.0 페이지·표 레이아웃 구현 및 검증 — 2026-10-26

## ① 명시적 페이지 나눔·구역 경계
- hp_block에 page_break_before / column_break_before / saved_break_before 보존.
- 문단 속성 pageBreak/columnBreak와 문단모양 pageBreakBefore를 리더에서 읽음.
- 하나의 원본 문단이 텍스트/표/텍스트 여러 블록이 돼도 첫 블록에만 나눔 적용.
- 빈 문단·개체만 있는 문단도 나눔이 남음.
- 구역 전환은 새 페이지를 시작하고 구역별 용지 크기·여백·단 간격으로 배치.
- 여백 0도 원본 값으로 인정하며 임의의 최소 40px 여백을 강제하지 않음.

## ② 표 제목 폭·정렬
- 언어별 장평/자간을 charPr에서 읽어 hp_run에 보존 (7종, 0 장평은 기본 100%).
- 설치된 원본 글꼴을 우선 사용하고 없으면 Malgun Gothic으로 대체. 폰트 확인은 캐시.
- GDI 측정과 그리기에 동일한 glyph advance/가로 배율을 사용.
- 저장된 줄의 가용 폭과 셀 안쪽 너비 중 작은 값으로 가운데/오른쪽 정렬.
- 원본 soft break가 현재 폰트/셀 폭에서 맞으면 유지하고, 초과하면 페이지 그룹 안에서
  텍스트를 연속 재배치. 마지막 글자만 별도 줄에 남고 다음 원본 줄이 다시 시작하던 현상을 완화.
- 열·병합 셀 너비·행 높이·여백을 공통 table_geometry로 계산.
- 셀 안에서만 그리되, 내용 측정·줄바꿈을 함께 적용하여 단순 클리핑으로 글자를 숨기지 않음.
- 음수 기본 여백(-1, XML에서는 4294967295)을 0 여백으로 해석.

## ③ 자동 페이지·긴 표 분할
- 원본 top-level 문단의 저장 좌표 초기화와 문단 내부 좌표 재시작을 경계로 적용.
- 페이지/단별로 block offset·높이·위치를 가진 조각을 저장하고 동일 블록의 다음 조각을 이어 그림.
- 일반 행/줄은 페이지 안에 들어갈 때 통째로 이동. 행 병합 중간은 가급적 피함.
- 페이지보다 큰 행은 연속된 clipped slice로 이어 표시하여 뒤쪽 내용을 버리지 않음.
- 단별 흐름과 새 구역 전환 지원. 페이지/블록 배열은 동적 할당.
- 반복 머리행, 각주/머리말 밴드, 매우 큰 병합 셀의 자연스러운 줄 단위 분할,
  부동 개체 회피와 완전한 원본 조판은 아직 지원 완료로 볼 수 없음.

## 자동 검증
- Windows CTest 14개 전체 통과.
- pagination: 페이지/단/문단모양 나눔, 빈 문단/개체 문단, 혼합 문단의 첫 블록만 나눔,
  언어별 장평/자간 보존.
- page-flow: 첫 빈 페이지 방지, 단 전환, 행 유지, 큰 블록 조각의 offset/총 높이 보존.
- gui-layout: 실제 GDI 측정/줄바꿈/명시적 개행, 강제 페이지와 문단 내부 재시작,
  긴 표/큰 행/다단/구역별 용지, 음수 셀 여백, 샘플 모든 블록의 연속 조각 범위 확인.
- Golden 6종에 새 breaks/metrics 행만 추가됐음을 이전 스냅샷과 비교 확인.
  새 행을 제거한 기존 문서 모델 출력은 이전과 동일함.
- 원본 보존 저장 및 손실 저장 거절 경로의 기존 테스트 유지.

## 샘플 결과
| 샘플 | 0.3.2 | 0.4.0 | 기준 PDF |
|---|---:|---:|---:|
| 윤리기준 | 16 | 20 | 17 |
| 규제합리화 | 24 | 29 | 20 |
| 식약처 | 4 | 4 | 4 |

페이지 수만으로 개선을 판정하지 않는다. 강제 나눔을 유지하고, 앞서 잘렸던 내용은 다음
페이지로 이어 표시하므로 이전보다 페이지 수가 늘 수 있다. 원본 페이지 소속·줄바꿈·표 높이와의
차이는 남아 있어 한컴 출력과의 전체 시각 일치 검사는 불합격 상태다.

## 실제 GUI 관찰
- 윤리기준 표지는 제목·날짜·기관 표시만 있고 목차는 다음 페이지에서 시작함을 확인.
- 규제합리화 첫 페이지의 큰 제목 끝 '개최'까지 셀 안에 표시되고 가운데 정렬됨을 확인.
- 설치된 원본 글꼴 사용으로 글꼴 외관은 달라졌으나 일부 작은 셀은 원본보다 더 줄바꿈됨.
- 최종본의 화면 재확인 범위는 표지/목차·샘플 첫 페이지. 모든 페이지/DPI 조건 전수 검사는 아님.
- 테스트 중 발견한 거대 여백 계산은 회귀 테스트로 고정하고 수정 후 샘플 레이아웃 전체를 재검증.

## 후속 개선
1. 저장된 줄 폭과 실제 글꼴 shaping/kerning 차이, 탭·양쪽 정렬을 정교화.
2. 표 머리행 반복과 큰 병합 셀 내부의 줄 단위 페이지 분할.
3. 중첩 표/문단/그림의 원래 순서 및 부동 개체 회피를 보존.
4. 전체 샘플의 PDF 대조와 여러 화면 배율 조건으로 확인.

[한컴 공식 도움말](https://help.hancom.com/hoffice_mac/ko_kr/hwp/format/font/fonts%28spacing%29.htm)을 참고.
