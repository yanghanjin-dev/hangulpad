# Sample: 공공부문 인공지능 윤리기준

- `documents/*.hwpx` — sample opened by `HangulPad.exe`
- The GUI reads this HWPX through the engine and paints styled
  paragraphs (font face/size/alignment/color) onto A4 pages.
- Optional `pages/*.jpg` are reference rasters from the PDF only;
  they are **not** required for viewing.
